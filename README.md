# 🍽️ Canteen Management System

## Description

A web-based application to manage canteen orders, generate tokens, and track orders efficiently.

---

##  Features

* Token generation
* Order tracking
* Simple UI
* Backend API support

---

##  Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js

---

##  How to Run

### 1. Clone repo

git clone https://github.com/Prasannavijayalakshmi-Menni/CanteenManagement.git

### 2. Install dependencies

cd backend
npm install

cd ../frontend
npm install

### 3. Run project

cd backend
npm start

cd ../frontend
npm start
